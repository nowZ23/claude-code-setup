# Skills

Les skills sont des modes d'emploi que Claude charge quand la tâche le demande (design, PDF, Word, Excel, présentations, recherche approfondie...). Ils ne sont pas copiés ici : ils viennent de marketplaces ou de dépôts publics et leur contenu appartient à leurs auteurs.

Pour les retrouver et les installer, passe par `/plugin` dans Claude Code ou par le dépôt de l'auteur. Les plus utiles pour démarrer :

- **Documents** : `docx`, `pdf`, `pptx`, `xlsx`
- **Recherche** : `deep-research`
- **Rédaction** : `doc-coauthoring`, `humanizer` (retire les tics d'écriture IA)
- **Design** : `artifact-design`, `canvas-design`, `theme-factory`
- **Création de skills** : `skill-creator`

Tu peux aussi écrire tes propres skills : un dossier `~/.claude/skills/<nom>/` avec un `SKILL.md` qui commence par un frontmatter `name` et `description`.
