# Squelette de vault Obsidian

Structure de départ pour la mémoire longue durée de Claude Code. À copier comme nouveau vault (`~/Documents/Claude/mon-vault` par exemple), puis enregistrer son chemin dans `~/.claude/obsidian-vault.path`.

```
vault/
  brain/            décisions, patterns, pièges, auto-critique
    retros/         rétrospectives de session (générées)
  work/active/      une note par projet en cours
  org/people/       une fiche par contact
  reference/        snapshots automatiques (repos git, etc.)
  thinking/         brouillons et réflexions datées
  templates/        modèles de notes
```

Fichiers fournis : `brain/Self-Critique.md`, `brain/Voix et style.md`, `brain/North Star.md`. Les dossiers vides contiennent un `.gitkeep`.
